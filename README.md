# Science Medicine Lab

Статическое учебное PWA: английский B1–B2 на материале научных публикаций, русские пояснения, упражнения, словарь и повторение. 8 уроков и 104 локальные аудиозаписи Microsoft en-GB-RyanNeural.

## Офлайн на iPhone

1. Откройте сайт в Safari при подключении к интернету.
2. Нажмите «Поделиться» → «На экран Домой».
3. Откройте приложение с нового значка.
4. В разделе «Прогресс» нажмите «Сохранить офлайн».
5. Дождитесь «Тексты и упражнения сохранены» и «Аудио: 104/104».

После этого тексты, упражнения, изображения и записи доступны без сети. Браузер может удалить кеш при нехватке места или очистке данных. Внешние ссылки на источники требуют интернета.

Прогресс хранится только в браузере, отдельно для каждого адреса сайта. Для переноса со старого адреса сначала экспортируйте прогресс там, затем импортируйте JSON на новом сайте. Кнопки находятся в разделе «Прогресс».

## Размещение

Сборка не требуется. GitHub Pages: Deploy from a branch → main → /(root). Относительные пути поддерживают адрес проекта в подпапке. Локальный запуск: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.

Оригинальный PDF журнала, персональные данные, секреты, аналитика и внешние CDN не включены. Тексты адаптированы для языкового обучения; это не медицинские рекомендации. Источники указаны в приложении.

## Проверка перед переносом

- Проверены 8 уроков, 32 абзаца, 48 словарных единиц, 32 вопроса, 104 ссылки на аудио.
- Все 104 MP3 совпали с исходными SHA-256 и полностью декодированы ffmpeg без ошибок.
- Аудио: 5 729 040 байт, 954,84 секунды.
- Физический iPhone/Safari и возможное вытеснение кеша браузером не проверены.
- В Chrome проверен путь `/science-medicine-lab/`, как у проекта GitHub Pages: кеш 104/104, повторное открытие после остановки сервера, переход в другой урок и воспроизведение записи из кеша (readyState 4, позиция 0,23 → 13,12 с). Это локальная проверка недоступного сервера, не проверка опубликованного Pages и не авиарежим физического iPhone.
